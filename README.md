# Amazon経理・利益管理ツール

Amazonセラー向けの無料Windowsアプリです。

## 主な機能

- AmazonトランザクションCSVの取込
- 売上・手数料・利益の管理
- 商品マスタ・原価管理
- 月次会計レポート
- PDF・Excel出力
- データのバックアップ・復元

## 対応環境

Windows 11
※Windows 10は未検証です。

## ダウンロード

β Ver.0.1を無料配布しています。
画面右側の「Releases」からダウンロードしてください。

## 注意事項

本アプリは無料β版です。
コード署名を行っていないため、Windowsのセキュリティ機能によって起動できない場合があります。

会計・税務処理については、税理士等の専門家にご確認ください。
